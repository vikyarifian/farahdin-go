# Testing Strategy

## Test Pyramid

```text
              E2E (manual + headless Chrome screenshots)
             /   \
        HTTP (httptest, real PostgreSQL)  ·  live upstream smoke (build tag "live")
          /       \
        Unit       Unit (domain, external, service with fakes, repository)
```

## Suites

| Package | What | Command |
|---|---|---|
| `internal/domain` | zodiac, age, reduceNumber, **matrix parity with the RN expressions** (`testdata/matrix_reference.json`, generated by evaluating the TypeScript formulas in Node), validation, title case | `go test ./internal/domain` |
| `internal/external` | selectors, cheerio `.text()`/parse5 `.html()` compatibility, JS-string pipeline, Translate encoding, body cap | `go test ./internal/external` |
| `internal/service` | each feature port with fake upstream pages; `createUser` port; profile validation | `go test ./internal/service` |
| `internal/repository` | users, sessions, migrations idempotency, Convex import (isolated schema per test) | `TEST_POSTGRES_URL=… go test ./internal/repository` |
| `internal/auth` | OIDC state, PKCE, unverified email | `go test ./internal/auth` |
| `internal/http/handler` | auth redirects (incl. HTMX 401), CSRF, session lifecycle, language + open redirect, profile 422/200, fragment vs full page, friendly upstream errors, matrix, PWA endpoints, headers | `go test ./internal/http/handler` |
| live upstream | every topic of every feature against the real sites | `go test -tags live -run TestLive -v ./internal/service/` |

## Regression

For each migrated journey compare entry state, outcome, validation, errors, navigation, permissions
and data changes with the React Native app (behavior-map.md). Remaining step for ledger rows in REVIEW.

## Database tests

Repository and HTTP handler tests need `TEST_POSTGRES_URL`, a database where the user may
`CREATE SCHEMA` (never production). `repotest.Open` creates a schema per test, migrates it and drops
it afterwards. Without the variable those tests are skipped. A throwaway server is enough, for example
`docker run -p 5432:5432 -e POSTGRES_HOST_AUTH_METHOD=trust postgres:16`.
