# Migration Documentation

This directory is the persistent memory of the React Native (`../farahdin-react-native`) → PWA migration.

## Files

- `inventory.md` — source application inventory.
- `behavior-map.md` — observable behaviour per journey, open questions (Q-xx).
- `api-map.md` — Convex functions, third-party requests, PWA routes.
- `data-map.md` — Convex → PostgreSQL mapping and the import procedure.
- `ledger.md` — migration status by journey (MIG-xxx).
- `deviations.md` — intentional behaviour differences (D-xx).
- `risks.md` — migration risks and mitigations (R-xx).

## Principle

Document what the existing application actually does before deciding how the PWA should implement it.
