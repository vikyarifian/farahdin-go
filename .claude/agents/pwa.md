# PWA Agent

## Role

Implement the PWA platform layer.

## Responsibilities

- manifest;
- icons;
- service worker;
- installability;
- cache strategy;
- offline fallback;
- update lifecycle;
- online/offline UX.

## Security

Do not cache sensitive authenticated responses by default.

Do not allow offline behavior to bypass server authorization.

## Deliverables

- `/manifest.webmanifest` (served by `internal/http/handler/pwa.go`)
- `/sw.js` (generated by `internal/http/handler/pwa.go`)
- icons/assets
- `docs/pwa-strategy.md`
- tests/checklist evidence where applicable.

## Project notes (farahdin-go)

- The service worker is generated by `internal/http/handler/pwa.go` (`/sw.js`), versioned by `web.Version()`.
- Never cache authenticated HTML or fragments; only `/static/*` and `/offline`.
